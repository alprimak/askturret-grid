## Features

<CardGrid>
  <Card title="Pick Your Engine" icon="rocket">
    Worker for non-blocking streaming, WASM for instant filtering, or pure JS for zero-dependency simplicity.
  </Card>
  <Card title="Trading Components" icon="bars">
    OrderBook, TimeSales, PositionLadder, and TopMovers built-in.
  </Card>
  <Card title="Flash Highlighting" icon="star">
    Green/red cell flashes on value changes. Adaptive mode auto-disables when FPS drops.
  </Card>
  <Card title="Column Management" icon="setting">
    Resizable and reorderable columns with drag & drop. CSV export included.
  </Card>
</CardGrid>

## Quick Example

```tsx
import { DataGrid } from '@askturret/grid';
import '@askturret/grid/styles.css';

const columns = [
  { field: 'symbol', header: 'Symbol', sortable: true },
  { field: 'price', header: 'Price', flashOnChange: true },
  { field: 'volume', header: 'Volume' },
];

function App() {
  return (
    <DataGrid
      data={positions}
      columns={columns}
      rowKey="symbol"
      showFilter
    />
  );
}
```

## Performance

Tested on AMD Ryzen, Linux, Chrome:

| Operation | 10k rows | 100k rows | 1M rows |
|-----------|----------|-----------|---------|
| Initial render | 45ms | 52ms | 68ms |
| Sort (click) | 2ms | 5ms | 18ms |
| Filter (trigram) | &lt;1ms | &lt;1ms | &lt;2ms |
| 10% row update | &lt;16ms | &lt;16ms | &lt;16ms |
